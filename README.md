# AWS Cloud Ops Adventure Android / AWS 云端运维指挥官

Native Kotlin + Jetpack Compose educational operations game. Entirely offline; no AWS account, SDK, credentials, backend, or `INTERNET` permission. This is an independent learning simulator, not an official AWS console. It creates no real resources and incurs no real AWS charges.

## Current delivery: 0.2.0

60 state-driven playable missions in 10 chapters with sequential unlocks; service simulators for IAM, EC2/EBS/AMI, VPC networking, S3/EFS, RDS/DynamoDB, ALB/ASG/Route 53/CloudFront, CloudWatch/SNS/Logs/CloudTrail, Lambda/Scheduler/SSM/CloudFormation, ECR/ECS/EKS, Organizations/KMS; Chinese/Japanese/English story, lessons and hints; resource console with metric chart; local CLI (`aws`, `sim`, `kubectl` subsets); draggable topology; 10-district chapter map; sandbox; scoring, stars, XP, coins, ten achievements; Room snapshots with versioned migration; DataStore language settings.

Content is still simplified in places — see [MISSIONS](docs/MISSIONS.md#known-simplifications) and [ROADMAP](docs/ROADMAP.md). The console uses a generic structured operation form; supported AWS CLI syntax is a documented subset. Executed results are in [VALIDATION](docs/VALIDATION.md).

## Build and install

Requirements: JDK 17, Android SDK platform 35, accepted SDK licenses. Wrapper pins Gradle 8.9, AGP 8.7.3, Kotlin 1.9.24 and Compose compiler 1.5.14. The [official AGP compatibility table](https://developer.android.com/build/releases/about-agp) documents the Gradle pairing. Initial build downloads dependencies; the installed game operates offline.

```powershell
.\gradlew.bat :core:test testDebugUnitTest lintDebug assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Linux/macOS: use `./gradlew`. Open this folder in Android Studio. Set `ANDROID_HOME` or a local, untracked `local.properties` containing `sdk.dir=...`.

```sh
python -m pip install jsonschema==4.23.0
python tools/validate_content.py
./gradlew connectedDebugAndroidTest
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`. The debug signing key is generated by Android tooling. Release artifacts are unsigned by default; see [release signing](docs/BUILD.md). Never distribute a debug build as a production release.

## First mission

Select **开始 / 继续游戏**. Inspect the objective list and resources. Use the console action panel, with resource ID and one `key=value` parameter per line. CLI can perform the same operations:

```text
sim delete base-a
sim region unused value=ap-northeast-1
sim create base-a type=base az=ap-northeast-1a
sim create base-c type=base az=ap-northeast-1c
```

Press **检查 / 领取奖励** after the state satisfies every objective. Rewards cannot be farmed by repeating claims. Reset preserves completed missions and progression, while restoring the selected mission world. Switching mission replaces the active workspace; one active world is saved.

CLI help is built in (`aws help`). An optional sandbox allows all supported operations without mission rewards. `sim identity NAME` selects a simulated test principal; return with `sim identity commander`. This is an educational principal selector, not a production authentication boundary.

## Structure

- `core`: immutable serializable models, IAM evaluator, command bus, service simulators, network evaluator, mission validator, CLI parser, save codec, JVM regression tests.
- `app`: Compose UI / Navigation, Hilt ViewModel/repository, Room saves, DataStore, offline assets, instrumentation tests.
- `schemas`: Draft 2020-12 mission schema.
- `tools`: reproducible content generation and schema/reference validation.
- `docs`: architecture, gameplay, rules, CLI, validation, roadmap.
- `.github/workflows/android.yml`: schema validation, JVM tests, Android lint, debug APK upload.

No arbitrary user scripts or OS shell commands are executed by the game. Unsupported CLI commands fail explicitly. Prices are versioned teaching values, not current AWS prices.
