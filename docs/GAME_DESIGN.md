# Gameplay

2035: Shadow Fault attacks cloud infrastructure. Commander Nova directs the response. Mira offers three local hint tiers; lessons explain each operation. No remote AI is used. Players inspect resource properties and audit events, perform operations using the console or CLI, and claim rewards after actual state validation.

Sequential missions unlock on completion. Claim grants 150 XP and 50 coins once per mission. Coins have no monetary value; spending and cosmetics are not yet implemented. IAM Guardian and First Instance are obtainable at missions 6 and 7; eight later achievement names remain locked. Achievement time is a deterministic simulation tick, not a real-world date.

Score: functionality 40, security 20, cost 15, efficiency 15, practice 10, minus 10 per hint. Broad wildcard grants reduce security; failed commands reduce efficiency. Cost points apply when budget objectives pass. Every functional objective and safety constraint must pass before completion, irrespective of score. Stars: 90+ three, 75+ two, 60+ one. A functionally complete mission below 60 may be completed with zero stars. Claiming again preserves the best star result and gives no duplicate XP/coins.

The current map is a zoomable/pannable Canvas with ten chapter markers and accessible mission buttons below. Chapter 3–10 text marks them planned. The topology reflects resource references and supports dragging nodes via commands. It does not evaluate connectivity. Console operations and teaching content currently use compact generic forms rather than a full AWS console replica.
