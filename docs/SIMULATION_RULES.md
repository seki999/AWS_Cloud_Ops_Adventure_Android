# Supported simulation rules

- IAM: users, groups, roles, explicit Allow/Deny, default deny, action/resource `*` patterns and group membership evaluation. Explicit deny overrides matching allows. EC2 role access needs `ec2.amazonaws.com` trust plus resource permission. Policy JSON containing Condition or unsupported semantics is rejected. Boundaries, SCP, sessions, real MFA and STS are not modeled.
- Resource mutations require IAM authorization and mission allowlist. Training principal selection is an explicit simulator control. Read-only CLI queries also authorize, using `*` for list/describe operations. The console is an instructor view of the world and does not restrict resource visibility per principal yet.
- EC2: creation validates supported instance type, existing AMI/subnet/SG, region and AZ compatibility. start only from stopped; stop/reboot only from running; terminate from running/stopped. Terminated cannot restart. Transitional states settle atomically in this MVP, with no asynchronous pending/stopping interval. Health depends on running state, application state and system flag.
- AMI records source ID and app state; clone inherits captured app state. No real image filesystem is emulated.
- EBS: valid positive size, independent fsSize and used space, same-region/AZ attachment, grow only after association. Expanding volume does not grow the filesystem. No shrinking. Deletion rejects references from remaining resources.
- Metrics: CLI reports deterministic CPU, simulated AgentMemory and health derived from current state. No random pass/fail. Historical samples are kept (bounded) and charted in the console.
- Costs: versioned teaching table (`pricing/v2.json`), one virtual second per command; instances, volumes, NAT, ALB, RDS (Multi-AZ doubled), EFS, S3 storage class and container tasks. Not AWS prices.
- Audit: every attempted command, actor, tick, success and message. Replaying the same commands from the same initial world reproduces state in JVM tests. Claims and hints also use commands; failed save never publishes partial state.
- Network (`Network.kt`): strict IPv4/CIDR (non-canonical CIDRs rejected), subnet-in-VPC and overlap checks, longest-prefix route selection, local route protected, IGW attachment + public IP for internet paths, NAT in an IGW-routed subnet for egress only. Security groups are stateful (return traffic implied); NACLs are stateless, lowest rule number wins, and the response path must allow ephemeral ports (49152). Endpoint health, application state and listening ports are required. Topology links never imply reachability.
- Storage: S3 versions/delete markers/restores, Block Public Access vs public-read, lifecycle transitions on the virtual clock, KMS-encrypted objects, EFS mounts over TCP 2049, EBS snapshots and restores.
- Databases: RDS readiness = available + network reachability on 5432; backups, restores, Multi-AZ in two AZs with failover; DynamoDB tables keyed by partition key.
- Traffic: target groups, ALB readiness from healthy reachable targets and capacity vs load, ASG member scaling, Route 53 records, CloudFront origin access.
- Monitoring: deterministic metric samples each tick, alarms over N periods, SNS notifications, alarm-triggered functions, logs, CloudTrail-style audit lookups, dashboards.
- Automation: Lambda with predefined behaviours only (StartInstance, RestartApplication) under its execution role; schedules; SSM documents on managed instances; patch fleets; CloudFormation subset (VPC, Subnet, S3 Bucket, SNS Topic) with per-child IAM checks.
- Containers: ECR image tags/digests, ECS task definitions/services with task-role trust, EKS deployments with image, port, probe and environment checks (ImagePullBackOff, CrashLoopBackOff, port mismatch).
- Security: Organizations SCP deny applied before IAM, KMS key policy + IAM for encrypt/decrypt, cross-region copies of buckets/backups (KMS-encrypted copies refused rather than faked).

The unsupported-operation response is explicit. CLI does not invoke Shell, AWS SDK, network APIs or execute user code. EC2 create CLI intentionally uses a simulator ID argument; this is not a full AWS CLI emulator.
